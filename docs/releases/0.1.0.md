# 0.1.0 — first Maven Central release

Published and public availability verified on 2026-10-09.

## Distribution

Group: `io.github.sosmex.push`.

- `push-core:0.1.0`
- `push-fcm:0.1.0`
- `push-onesignal:0.1.0`
- `push-test:0.1.0`

All four modules include Kotlin Multiplatform metadata, Android AARs, JVM
artifacts, and iOS device (`iosArm64`) and simulator (`iosSimulatorArm64`) KLIBs.
Use `mavenCentral()`; consuming these packages requires no registry token.
See the [installation guide](../getting-started.md#install-from-maven-central).

## Integration boundaries

Applications still configure native Firebase or OneSignal SDKs and forward
platform callbacks. iOS KLIBs support KMP consumption, not direct Swift Package
Manager installation. These publication checks do not establish real push
delivery on physical devices; follow the [device checklist](../getting-started.md#before-calling-your-integration-ready).
